# T4 角色培养包

这里保存可重复导入 Role Library 的非敏感培养材料。它们不是运行时
`data/memory/roles`，也不会在启动时自动上架；每个角色仍须经过
`draft → validating → ready`，并由用户明确确认发布。

固定培养顺序：

1. `linzhou/`：完全虚构、事实边界可控，用来验证沉浸、未知项和世界线。
2. `freud/`：历史人物，必须带公开来源、时期边界与后世观点隔离。
3. `editor/`：工作角色，用来验证 RoleContract、项目记忆和受控 Workspace 工具。

培养包只提供输入素材与验收契约，不绕过编译器、来源校验或 UI 中的“模拟角色”标识。
