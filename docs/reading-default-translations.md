# 默认译文与个人重译

## 使用契约

- 默认译文按作品、原文版本、目标语言保存，全站复用；普通入口统一采用通顺译本。查看已有译文不调用模型。
- 当前样例使用 AI 辅助译文，不称为出版社或名家译本。支持英文转简体中文，以及《桃花源记》《木兰诗》《劝学》课文节选转现代汉语；《孔乙己》《背影》保留现代汉语原文。
- 单句重译只更新当前读者的个人译本；整篇重译在独立草稿中按批生成，全部完成后才替换个人有效版本。失败和暂停保留原有有效译本，重开页面可以续译。
- 个人译本和默认译本可以切换阅读；切换不会删除个人译本。默认和个人版本均不改变原文、阅读位置、聊天记录或故事分支。
- 同名读者仍共享同一身份，这是现有笔名登录约定，并非密码权限系统。

## 原文定位现状

初版遗漏了滚动跟随，后续已补齐：默认在停止滚动 450ms 后，以原文可视区上方约三分之一处的段落更新讨论位置并保存。手动下拉、段落编号、导读或书签选段会固定讨论位置，可点击“恢复自动跟随”。正在输入问题、写笔记、生成回答或打开弹窗时暂不跟随；滚动聊天列表不改变原文位置。选择段落不调用模型，也不会自动开启全书讨论。

## 持久化与兼容

- 打包默认译文：`internal/story/translations/<book>.json`，由 Go embed 随二进制发布。
- 运行时生成的共享默认译文：作品根目录下 `shared-translations/<text-version>-sentences-v1-zh-<style>.json`。
- 个人译文：保持既有读者目录下 `translations/` 路径；不自动将旧个人译文提升为公共资源。
- 重译中的草稿：个人译文路径追加 `.pending`；只向当前读者返回任务 ID 和进度，未完成的内容不会替换有效译本。
- 来源哈希、句子 ID、段落号、字节位置与完整原句全部校验。原文更新时旧打包译文不会错位套用；损坏的运行时存档报错，不静默覆盖。
- 共享生成锁覆盖所有读者；个人生成锁按读者隔离。当前部署为单实例；文件锁不支持多个进程同时写同一数据目录。
- 个人重译使用有效译本指纹校验，拒绝旧页面覆盖新版本。整篇续译使用任务 ID 和已完成句数，重复请求不会重复翻译已确认批次。

## 接口

沿用需读者登录的 `GET/POST /api/story/companion/translation?book=<id>`：

- GET 默认返回当前读者的有效版本；`edition=default` 可查看共享默认。
- POST `{style:"fluent",completed:0}` 首次生成或继续共享默认译本。
- POST `{action:"retranslate",style:"fluent",sentence_id:"p1-s1",revision:"<GET 返回的指纹>"}` 重译个人单句。
- 整篇重译省略 sentence_id；下一批带上返回的 `pending.id` 作为 `run_id`，`pending.completed` 作为 `completed`，继续携带有效版本的 revision。
- 所有个人身份从服务端读者会话解析，不接受客户端提交的文件路径或 owner。

## 样例预制与发布

`go run ./cmd/seed-translations -run -env <环境文件> -books <逗号分隔的作品 ID>` 仅处理仓库公版原文，不读取个人资料。输出默认译文到上述打包目录，独立断点缓存位于被忽略的 `data/translation-seeding/`。可用 `-batch-size 8` 缩小批次。没有 `-run` 时不调用模型。

默认资源加入仓库后，重新构建前端与 Go 程序即可随服务器发布。不需要迁移读者私人译文或临时生成缓存；服务器旧个人记录保持原路径。本轮只准备本地版本，不自动部署。

## 验证范围

- 单元测试：跨读者缓存复用、个人单句隔离、未选句不变、旧指纹拒绝、未知句子拒绝、整篇失败和恢复、重启、并发检查、古文逐句字节定位。
- 前端测试：默认只读取、整篇确认、个人任务续译、单句参数、默认/个人切换、古文入口。
- 默认资源需全部通过完整性检查：版本匹配、无缺句、无重复句、原文字节一致、无空译文、关闭模型仍可读取。
- 这些检查保证结构与持久化，不等于专业译者对每一句完成终审。样例保留 AI 辅助标识，允许个人重译。

### 浏览器实际检查

使用 `TestReadingTranslationBrowserFixture` 的独立临时目录与两句虚构原文、模拟翻译器，不读取生产读者数据，也不调用模型网关。已完成默认译文直接读取、第二句个人重译、首句不变、切回默认、重新查看个人译文、整篇重译确认与完成后替换的检查。测试读者：`译文隔离验收0914`。

手工启动此夹具时应加 `-timeout 12m`，避免 Go 默认十分钟超时与夹具自身十分钟退出计时相撞。

合计 922 句。《项链》首次批次因漏句被拒绝保存，随后使用每批八句重试完成；没有用缺失句凑足进度。抽查并校正部分古文措辞及人物译名，并给后续默认生成和个人重译提供固定人名表。这里的人工抽查不意味着逐句出版级审校。

前端 78 项测试通过；全量 Go 回归通过，另做翻译并发检查。七篇内置译文的自动验收覆盖完整性、跨读者同版复用、关闭模型仍可读以及原文变化不复用旧位置。
