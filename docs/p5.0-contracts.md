## 硬边界

- Soul 永不进入 Proposal 目标，不可被 Dream 改写。
- 仅 `simulated_roleplay` / `story_reading` 证据最多升到 `tentative` Pattern，不得单独升 `principle`。
- 自主回合（P7）默认不进 mudnet STM / 聊天时间线。

---

## 1. SelfArtifact = 文件真相 + Graph 指针

```text
data/memory/self/
  patterns/
  principles/
  tensions/
  questions/
```

- 文件保存正文、修订史、来源 Episode、置信度。
- Neo4j `SelfArtifact` 只保留：`id` / `type` / `status` / `summary` / `confidence` / `doc_uri` / 时间戳。
- 边：`(Self)-[:CONSIDERS]->(SelfArtifact)`，`SUPPORTED_BY` / `CHALLENGED_BY` → Episode，`TENSION_WITH` → SelfArtifact。

类型：`pattern | principle | tension | question`  
状态：`observation | tentative | claimed | deprecated`

---

## 2. Proposal 同基础设施，按 kind 分策略

```text
kind = bond | self_pattern | principle | tension
```

共享队列、status、Mutation Ledger。  
Review Policy 分开：Bond / SelfPattern / Principle / Tension。  
Principle 形成门槛显著高于 Bond。

---

## 3. Episode `experience_mode`

```text
real_interaction | simulated_roleplay | story_reading
| external_observation | self_reflection
```

- 缺省（旧文件无字段）：`real_interaction`
- 与 `kind` 正交：例如 `kind=self_note` + `experience_mode=simulated_roleplay`
- 证据权重：真实互动 ≫ 角色代入 / 读故事 ≫ 模型瞬时自述

---

## 4. Autonomous Turn 与 Chat Session 隔离

```text
session_id = auto:<intent_id>:<attempt>
trigger = SELF_SCHEDULED | ...
person = null / self
```

长期产物只进 Episode / Workspace / Intent / Self Proposal / Receipt。  
默认不进聊天时间线。

---

## 5. ExecutionQueue

同一 `agent_id` 同时只允许一个认知性 Turn（聊天、Review、Dream、未来自主回合）。  
纯 IO（web fetch）可并发；改记忆 / 提案 / 回复必须单线程提交。

---

## 6. Intent catch-up / stale

服务停机后的周期 Intent：合并 missed ticks，只唤醒一次并说明逾期。  
一次性 Intent 逾期时明确 `stale_days`，不假装「刚好到点」。

决策：`continue | reschedule | cancel | do_now`

---

## 7. Maintenance dirty signal

```text
dirty + cooldown + budget → MAINTENANCE opportunity
```

禁止「每 N 条 Episode 强制 Dream」。Agent 仍可 noop。

---

## 8. P8 安全契约（先于工具）

- 仅 http/https；禁 file、localhost、RFC1918、link-local、云 metadata
- DNS resolve 后再验 IP；Redirect 后再验
- 体积 / 超时 / Content-Type / 日预算限制
- 网页正文包裹为 `UNTRUSTED_EXTERNAL_CONTENT`，不得获得 System 权力
