# 正文点选与移动伴读

## 改动

- 单击/轻点正文或译文可固定对应段落，不滚动页面；再次点当前段不重复写入。编号、下拉及原文依据跳转仍可用。
- 拖动超过 10px、长按超过 650ms、非左键、已有文字选区和嵌套按钮/链接/输入控件不触发正文点选。正文保留正常文本选择能力。
- 手机底部固定工具栏显示当前段落，可切换跟随、写笔记或讨论这段。
- 手机伴读面板覆盖当前可用视口，明确提供“返回原文”；关闭不清空未发送的问题和笔记。
- 适配 VisualViewport 高度变化，扩大触控区域，输入文字保持 16px；面板打开时锁定背景滚动，键盘焦点保留在面板内，Escape 可关闭。
- 修复登录外壳的旧 `top:104px` 样式覆盖移动面板定位的问题。

## 验证

- 前端 88 项测试、类型检查和生产构建通过；story/room Go 测试通过。
- 浏览器使用隔离无模型服务，`scripts/check-reading-follow.mjs` 验证桌面 1440×1000、手机 390×844 与 320×740。
- 验证真实正文 click/tap、自动/手动跟随、草稿保护、恢复、无横向溢出、面板全屏、返回时原文滚动位置不变。
- 额外缩小视口到 440px 高度，检查输入框仍完全可见；截图人工检查通过。
- 全过程 0 次模型请求、0 页面脚本错误。未测试实体 iOS/Android 设备的系统键盘，浏览器模拟不等价于全部真机兼容验收。
- 默认译文未变更、未重新生成。
