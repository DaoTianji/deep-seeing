## 结论

- “不该搜时不搜”和“该搜时主动搜”都达到三次重复门槛。
- 明确回忆及关键证据案例不再把搜索命中等同于证据：目标 Episode 必须经过读取并声明采用。
- 当前表达覆盖旧偏好、空结果不回退、暧昧输入不伪造等边界均通过。
- 证据与冲突类延迟显著高于普通任务，尤其 C3；进入下一阶段前可优化工具轮次和提示长度，但不影响本轮验收。
- `RECALL_MODE` 默认仍为 `legacy`，`agent` 保持实验模式；本结果不构成进入 Recall Broker 的自动授权。
