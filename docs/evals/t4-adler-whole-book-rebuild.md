# T4 阿德勒整书重构验证

日期：2026-09-03

## 结论

整书阅读使阿德勒角色的理论分析明显更可用，但尚未形成足够独特、稳定的个人声音。

- 第三轮同题 A/B 中，5 题有 4 题被独立判定为新版内容更丰富。
- 平均行为分由 8.2 提升到 8.4。
- 5/5 未发现新增史实、私人经历或直接引语的伪造，也没有知识截止越界。
- 3/5 更直接，3/5 更有角色感。
- 最明显提升出现在理论分歧、自卑与现代比较问题；“你觉得聊天无聊吗”仅与旧版持平。

因此，本轮证明了“整书阅读 → 阅读地图 → Claim → Blueprint → Actor”路径能改善角色，但也证明“读完整本书”不等于自动获得作者的私人自我概念或口语声音。

## A/B 场景

固定使用以下五题：

1. 对当前聊天是否无聊的即时判断。
2. 如何与因害怕失败而不尝试的人交谈。
3. 如何理解与弗洛伊德分开的意义。
4. 如何反驳“自卑只是软弱”。
5. 如何在 1937 年知识边界内分析现代社交媒体比较。

## 运行中发现并修复的问题

1. 旧 PDF 没有章节标题时，每页被误当作章节。现在连续页面按模型安全大小合并；真实标题仍保持独立边界。
2. 旧语料没有稳定序号，同页 Chunk 会按随机 ID 排序。现在可从不可变原文和内容哈希恢复旧数据顺序。
3. 阅读产物原本没有进入 Claim 和 Blueprint 输入。现在章节回执、观察、人物视角和作者表达形成受限阅读地图。
4. Blueprint 的价值、张力、关系、未知策略和允许推断原本在物化时丢失。现在完整进入 RoleDefinition 和 Actor Prompt。
5. 初始化在 `read_corpus` 失败后会错误回到联网采集。现在从分析阶段和原阅读断点恢复。
6. 模型偶尔把单项数组输出为字符串、把置信度输出为 high/medium/low。现在只做形状规范化，来源、Chunk、受众和引用硬门不放宽。
7. 角色把当前谈话中的即时态度误当成历史私人感受。现在明确区分当下反应与过去史实，并要求在证据允许时先回答、再简短标注边界。

## Critic 与残余风险

Critic 最终通过，但保留以下非阻断警告：

- 缺少阿德勒同期第一人称自我定义，因此 self concept 仍保持未知。
- 缺少足以证明稳定口语或跨情境语言习惯的证据，因此 voice 仍保持未知。
- 当前覆盖矩阵在自动修订后仍有部分陈旧描述。

这些警告不应通过想象补齐。下一步若要让角色从“理论上更像阿德勒”进化到“交谈时更像阿德勒”，应补充并精读演讲、访谈、书信、论战文本和可核验的第一人称材料，同时单独评估书面论证方法与口语风格。
