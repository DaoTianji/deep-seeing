## 仍然存在的问题

1. **跨会话题的两次召回均在约 15 秒后超时并回退 BM25。** 它没有生成完整最终答案，保留为失败；没有答错后重跑。尚不能确定后端具体慢在哪一层。
2. **正确不等于表达质量理想。** 偏好题虽然通过分类评分，仍加入其他软件和通用资源；知识更新题虽然选择了新值，却附带不必要的保留说明。
3. **流式 token 重复累计风险。** 已用独立账本避开错误收费估算，但 Runtime 统计代码还需要后续修复及兼容性测试。
4. **失败的入库可能留下部分派生记录。** 预算中断后，第六题的一段留下文档、事实和片段。恢复前备份了独立测试数据库，只清理该派生文档并核验归零，原始 Episode 和已成功索引未删除；随后重建并取得完整成功回执。备份可用于恢复，没有操作生产数据库。

因此，目前的结论是：**已看到比旧六题样本更好的、可追踪到证据的表现，但集成可靠性和首次建库成本仍需改善。** 不应据此直接启动昂贵的 500 题全量测试。
