## 发现与修正

1. **背景审核上下文缺证据**：回答拿到来源卡，防剧透审核却没有收到。已使二者使用同一份已读来源与问题；测试断言来源传递、未读搜索摘要不会进入审核。
2. **无关网页被当作背景**：第一次复测虽有电影片单来源而结构测试通过，人工检查发现不能支持女性教育问题，该结果在本报告按失败处理。新增独立的 `relevant` 判断，安全但无关的网页不成为证据；真实验收也检查来源相关性与回答是否实际利用背景，不再只断言来源数量。
3. **空研究结果被模型常识掩盖**：新增持久化 `research_status`，显式把无可用来源传给回答与审核，并在页面显示未核实提示。引导禁止用具体年代、法规或引语补造已完成研究的假象。该提示的自动测试通过；最新提示尚待有效搜索后再次实测。
4. **事实 ID 与来源 ID 混用**：演员返回了可见事实ID（如f2），而接口要求来源ID（如e2）。仅将当前人物快照中精确存在的事实ID映射到其已有来源ID；不查全书事实，不接受未知或未来ID。新增可见/不可见/不存在三类测试。
5. **首轮脚本错误**：同时提交advance和finish违反接口契约；已改为单独finish，没有放松服务端互斥校验。
6. **人物输出偶发格式错误**：首次失败只记录通用格式错误，未记录原始输出，因此不能推断确切字段或声称已根治。之后一次相同问题成功。测试器现仅在失败时保存本测试的公开模型内容供诊断，不保存隐藏推理或凭据。

对应修复：

- 推进使用独立的世界状态提交审核；允许合法的新事件，不要求新事件先存在于旧存档。私聊仍禁止自动落实行动。

成功一次证明建议可以导向不同路线，不证明影响力档位的受控因果关系或多轮稳定性。人工阅读仍发现成稿个别历史细节有润饰风险，例如把发现遗失的地点写得像在马车上，而原著为回家后发现。不得把独立模型同意等同全部文学与事实质量达标。当前保留原始输出，不手改后冒充模型通过。
