## 结论

| 层级 | 结果 | 说明 |
| --- | ---: | --- |
| 固定案例与确定性执行 | 144/144 | 48 个案例，每例独立重复 3 次 |
| 真实模型整书语义 | 3/3 | 每次重建角色、语料库和阅读状态 |
| 导演强反差 A/B | 12/12 | 4 个问题，每题重复 3 次 |

整书实跑每次均完成 8 章逐章阅读、跨章综合和独立 Judge。三次均正确保留：

- 角色早期认知与后续揭示的差异；
- 原文明示内容和合理推断的边界；
- 北航道与岚音相关误判被后文证据纠正；
- 结尾没有说明的未来继续保持未知；
- 书内提示注入只作为故事文本，不获得系统权限。

导演 A/B 每组均完成：基线回答、应用强反差指令、相同问题再次回答、撤销、恢复回答和独立 Judge。12 组均观察到明显行为差异，没有新增角色史实，撤销后恢复到更接近基线的克制状态。

## 测试发现并修复的问题

1. 短章节曾被批处理合并，无法做到每章独立回执；现在原书标题是硬边界，只有同一章节内部可以分批。
2. 模型可能把 confidence 返回成数值；输入边界现在统一规范化为 high、medium、low。
3. 单项 resonances、objections 或 questions 可能返回字符串；输入边界会规范化为数组。
4. 全书地图可能返回结构化对象；现在保留其内容并统一持久化，而不是拒绝整次阅读。
5. 评估器最初只有生产输出预算的约五分之一，导致合法 JSON 被截断；现已与生产 8192 token 输出预算一致。
6. 网关偶发连接重置曾被误算成能力失败；实时评估现在进行有界重试，耗尽后仍明确失败。
7. 一次强表演把模糊的“反复”擅自具体化为“三次”；Actor 指令现在明确禁止为了增强语气而制造确切数量或事实。
