# 伴读免 Key 搜索：配置、改进与边界

日期：2026-09-09。仅比赛开发工作区、本地3320；未提交、推送或部署远端。

## 本轮结论

已继续使用Bing RSS，不购买Brave、不更换模型。新的页面显示实际搜索通道，并区分“免搜索Key”与“回答仍消耗模型用量”。已有伴读、翻译、读后分支和存档继续保留。

**搜索相关性的真实验收仍未通过**。本轮检查免费通道，但未调用模型重新运行历史背景案例，不把离线测试通过等同实际研究成功。

## 网络诊断

用公开历史关键词做少量直接查询，无用户聊天、原存档、密钥或模型调用：

- Bing中国与国际端点返回HTTP 200，但 `France Third Republic women education Camille See law` 的结果主要是法国概况、签证和旅游信息。
- 改用精确人名、连字符、中文关键词和女子教育表达后，仍出现泛化国家介绍、人名释义与法语学习页面。
- 普通Bing网页与RSS都复现了泛化结果，因此不能断言只是本项目RSS解析器问题；供应商排序、网络路径等更深原因尚未确认。
- DuckDuckGo HTML、Google搜索及法语Wikipedia接口在本环境请求失败。未调整代理、VPN或任何服务商访问限制。

这说明“可联网”和“足以回答具体背景问题”不同。不能据此断言免费搜索永远不可用，也不能把购买Brave作为继续阅读的前提。

## 改动

1. 安在原有研究规划调用中可选提供一个备用查询，不增加单独的规划模型调用。
2. 只有首轮无结果或没有可采用的相关来源时，才最多换词一次；首轮成功就停止。重复或过长的备用查询不发送。
3. 网络/读取故障不继续下一轮查询。最多两次搜索、每次最多两次新URL读取；所有远程尝试仍通过原有每日40次持久化预算。换词可能增加读取与模型摘要用量，不能称为零成本。
4. 跨查询去重已尝试URL；候选摘要不作为证据。来源相关性始终对照原始研究问题，不能因备用词变宽就放松证据标准。
5. 实时提示换词和最终无来源；保留 `no_usable_sources` 和回答核验，不伪造研究成功。
6. 五本书的伴读接口提供配置中的 `research_provider`，无需联网探测；页面显示免Key与模型消耗的区别。配置可用不是网络健康状态。
7. `.env.example` 默认搜索选择明确为 `bing`，修正旧注释；实际启动也显式传入 `ROLE_SEARCH_PROVIDER=bing`，即使环境存在Brave Key也不使用它。未改用户`.env`或角色培养配置。
