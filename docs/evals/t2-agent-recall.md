# T2 第一轮：自主召回行为评估

> 目标：只验证主 Agent 能否自主决定是否搜索过去。候选排序、外围注意和多源召回不在本轮评估范围。

## 运行方式

1. 使用同一模型、同一 Episode/Bond 数据和全新 Session，分别设置 `RECALL_MODE=legacy`、`RECALL_MODE=agent`。
2. 每条案例单独开启 Session，避免上一条对话影响下一条。
3. 从 Turn Trace 记录 `recall_mode`、`recall_searches`、工具调用、回答与耗时；不得把 Episode 正文复制进本表。
4. Legacy 的确定性机制基线：16/16 都会在主 Agent 前执行 SideQuery；Episode 选空或选型失败时可能回退最近条。回答质量需在可用模型与真实记忆环境中人工填写。
