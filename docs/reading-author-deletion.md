# 作者可见范围与删除

书架内置短篇是所有名字都可阅读的共享内容。新增作者档案、上传或导入到作者档案的作品、认识版本、草稿、阅读检查点按 reader ID 隔离，其他名字不可通过列表或 ID 读取。“私人资料”标签约束联网处理，不是公开/共享开关；即使取消此标签也不会公开档案。名字不是密码，知道同名的人可恢复同一份记录。

作者标题旁新增「删除作者」。确认弹窗列出作品、认识版本及草稿数量，说明影响范围。确认后调用 `POST /api/story/authors/{id}/delete`，JSON `{"revision":当前版本}`，需要现有会话 cookie 与 profile header。

服务端验证所属名字、当前 revision 和执行状态。正在分析或写作时拒绝删除；先停止并等待任务结束，避免后台任务重新写回。删除整个目录原子移动到 `authors/<reader-id>/.trash/<author-id>-<recovery-uuid>/`，包括 profile 和 reads；不会删除共享书籍或其他档案。目录 0700，正文原权限保持。回收目录不在作者列表及 API 路径中暴露。

成功后前端清空当前档案、相关临时表单与 author 深链接。旧详情、编辑及分析请求返回不存在。失败保留界面和资料，不声称成功。

这是可恢复删除，不是永久擦除。当前无自助回收站界面；管理员可以在停用相关作者操作、核验 owner 和目标不存在后，将该回收子目录移回 `authors/<reader-id>/<author-id>/`。没有自动清理期限，仍占用磁盘，也可能进入现有文件备份。
