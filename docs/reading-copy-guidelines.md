# 书中见：界面文案约定

阅读产品名称统一为“书中见”；安是伴读角色，不是产品名称。普通 Deep Seeing 页面不改名。

## 语气

- 说明用户可以做什么、操作结果是什么。不要替用户预设情绪、亲密关系或成就。
- 不用装饰性英文口号，不用“回声”“足迹”“走进人生”等隐喻替代功能名。
- 文学性留给作品与讨论。原文、用户笔记、故事正文与历史回答不作批量改写。
- 状态如实说明：加载、保存、生成、失败。没有生成成功，不能称已完成。
- 伴读不改原著；故事改写单独保存。人物回答是模拟，不冒充原文或历史事实。
- 名字不是密码；同名可访问同一记录。这一限制不得用温情文案掩盖。

## 统一用词

书架、阅读进度、书签、阅读笔记、伴读对话、故事记录、结局卡、确认署名。
“结束阅读”打开读后选项；“让故事走向结局”请求生成结局；二者不能混用。

## 本轮范围

清理登录、书架、阅读侧栏、读后选项、故事入口、结局卡和作者工作台的框架文案。
缩短书架与登录页的大标题区域，提高常用操作字级，保留现有配色与阅读布局。
不修改阅读内容、记录、模型与权限机制，不新增付费调用。
